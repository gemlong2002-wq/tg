# 手寫黑板 桌面小工具:安裝步驟

裝好之後,iPhone 桌面上會直接顯示「對方傳給我的最新一張」黑板圖,右下角有送出時間。
點一下小工具會打開手寫黑板網頁,可以回畫。

**你和太太的手機要各自安裝一次,各自填自己的身份碼。**
全程在 iPhone 上操作,大約 5 分鐘。

> 先確認 Boss 已經把最新版 push 到 GitHub,而且 GitHub Pages 已啟用,第 2 步的網頁才打得開。
> Scriptable 的介面是英文的,下面會寫出要按的英文按鈕名稱。

---

## 第 1 步:安裝 Scriptable(免費)

1. 打開 App Store,搜尋 `Scriptable`
2. 找到圖示是黑底白色程式符號、開發者為 Simon Støvring 的 App,按「取得」安裝

## 第 2 步:複製小工具程式

1. 用 iPhone 的 Safari 打開這個網址:
   `https://gemlong2002-wq.github.io/tg/widget/install.html`
2. 按黃色的「**複製程式**」按鈕
3. 看到「已複製!」就可以了
   - 如果顯示「自動複製失敗」:長按下方的文字框 →「**全選**」→「**拷貝**」

## 第 3 步:在 Scriptable 新增腳本並貼上

1. 打開 Scriptable
2. 按右上角「**＋**」,會出現一個空白的編輯頁
3. 點一下空白處,長按 →「**貼上**」(英文介面可能顯示「**Paste**」)
4. 點最上方的標題(預設叫 `Untitled Script`),改名為 `手寫黑板`

## 第 4 步:填入你自己的身份碼

1. 在貼上的程式最上面,找到這一行:
   ```
   const SECRET = '';
   ```
2. 把游標點在兩個單引號 `''` 的**中間**,輸入你自己的 4 位數身份碼
   - 改完長得像:`const SECRET = '你的四位數';`(單引號要留著)
   - 老公填老公的,老婆填老婆的
3. 其他地方都不要動
4. 按左上角「**Done**」存檔

> ⚠️ 身份碼只填在自己手機的 Scriptable 裡,不要截圖分享、不要貼給 Claude。

## 第 5 步:先試跑一次

1. 在 Scriptable 的腳本列表,點一下「手寫黑板」那張卡片
2. 會跳出小工具預覽:
   - 看到對方的黑板圖,或「還沒有訊息」→ 成功
   - 看到「⚠︎ 身份碼錯誤」→ 回第 4 步檢查身份碼
   - 看到「⚠︎ 請先在腳本裡填入身份碼」→ 第 4 步沒填到單引號中間
3. 往下滑或按「**Close**」離開預覽

## 第 6 步:把小工具放到桌面

1. 回到 iPhone 主畫面,**長按空白處**直到圖示開始晃動
2. 按左上角「**編輯**」→「**加入小工具**」
3. 搜尋 `Scriptable`,點進去
4. 左右滑動選「**中**」(長方形)或「**大**」(正方形)尺寸 → 按「**加入小工具**」
5. 小工具出現後,先別急著按完成:**長按這個小工具** →「**編輯小工具**」
6. 「**Script**」那一欄點一下,選「**手寫黑板**」
7. 其他欄位(When Interacting、Parameter)維持預設,點空白處關閉
8. 按右上角「**完成**」

完成!桌面上應該會看到對方的最新一張黑板圖。

## 常見問題

| 狀況 | 說明 |
|---|---|
| 小工具很久才換新圖 | iOS 決定小工具多久更新一次,通常 5~15 分鐘,手機省電或很少看桌面時會更久。想立刻看,點小工具打開網頁就是最新的。 |
| 點小工具打開的是 Safari | iPhone 的限制,小工具只能用 Safari 開網頁,沒辦法直接開「加到主畫面」的那個黑板圖示。 |
| 顯示「⚠︎ 身份碼錯誤」 | 第 4 步的身份碼打錯,或 Boss 在後台換了身份碼 → 回 Scriptable 改 `SECRET` 那一行。 |
| 顯示「⚠︎ 連線失敗」 | 手機當下沒網路,等下一次自動更新,或打開 Scriptable 手動執行一次。 |
| 小工具一片空白、寫著 Select script | 第 6 步的第 5~6 項沒做,要選「手寫黑板」腳本。 |
| 顯示「⚠︎ 伺服器回應格式錯誤」 | 後端暫時出問題,通常稍後會自己恢復;一直出現再請 Boss 檢查 GAS。 |
| 之後程式有更新 | 重做第 2~4 步:把舊內容全部刪掉、貼上新版、重新填身份碼。 |
