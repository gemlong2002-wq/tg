# 手寫黑板後端:手動部署步驟

這份是給 Boss 自己操作的步驟,大約 10 分鐘。全程在瀏覽器裡完成,不需要懂程式。
建議用電腦操作(手機畫面太小,不好點)。

---

## 第 1 步:建立 GAS 專案

1. 用你的 Google 帳號打開 <https://script.google.com>
2. 按左上角「**新專案**」
3. 按左上角「未命名的專案」,改名為 `手寫黑板`(名字隨意,自己認得就好)

## 第 2 步:貼上程式

1. 左邊檔案列表會有一個 `程式碼.gs`(或 `Code.gs`),點它
2. 把右邊編輯區裡原本的內容**全部刪掉**
3. 打開本 repo 的 `gas/Code.gs`,**全選、複製**,貼到編輯區
4. 按上方的「💾 儲存」圖示(或 Mac 按 `⌘ + S`,Windows 按 `Ctrl + S`)

## 第 3 步:設定共用通關碼(SHARED_SECRET)

這個通關碼是你和太太在網頁上第一次使用時要輸入的密碼。

1. 點左側齒輪圖示「**專案設定**」
2. 往下捲到「**指令碼屬性**」,按「**新增指令碼屬性**」
3. 「屬性」欄填:`SHARED_SECRET`(一字不差,全大寫)
4. 「值」欄填:你自己想的通關碼(建議 8 個字以上,不要用你其他帳號的密碼)
5. 按「**儲存指令碼屬性**」

> ⚠️ 通關碼只告訴太太,不要貼到聊天、不要寫進任何檔案或給 Claude。

## 第 4 步:先授權一次

程式需要存取你的 Google 雲端硬碟來存圖片,第一次要你親自同意。

1. 點左側「**< >**」圖示回到編輯器
2. 上方工具列有個下拉選單,選 `doGet`
3. 按「**▷ 執行**」
4. 跳出「需要授權」→ 按「**審查權限**」→ 選你的帳號
5. 如果看到「Google 尚未驗證這個應用程式」:按左下「**進階**」→「**前往 手寫黑板(不安全)**」
   (這是你自己寫的程式,所以 Google 才會這樣提醒,屬正常現象)
6. 按「**允許**」
7. 下方「執行記錄」出現「執行完畢」就完成了

## 第 5 步:部署為網頁應用程式

1. 右上角按藍色「**部署**」→「**新增部署作業**」
2. 「選取類型」旁邊的齒輪 → 選「**網頁應用程式**」
3. 填寫:
   - 說明:`v1`(隨意)
   - 執行身分:**我**(你的 Gmail)
   - 誰可以存取:**任何人**
4. 按「**部署**」
5. 畫面會出現「**網頁應用程式網址**」,長得像 `https://script.google.com/macros/s/一長串/exec`
   → 按「複製」,先貼到備忘錄存著

> 「任何人」的意思是網頁不用登入 Google 就能連,但沒有通關碼的人什麼都讀不到、也存不進去。

## 第 6 步:確認部署成功

把剛剛複製的網址貼到瀏覽器打開,看到下面這行就代表成功:

```
{"ok":true,"message":"tg backend is running"}
```

## 第 7 步:把網址接到網頁上

把第 5 步的網址交給 Claude Code(或自己改),填進 `index.html` 最上方程式區的這一行:

```js
const GAS_URL = '';
```

改成:

```js
const GAS_URL = 'https://script.google.com/macros/s/一長串/exec';
```

填好後網頁上「測試模式」標籤會消失,開始走真的後端。

---

## 之後如果程式有修改,要怎麼更新?

**不要**再按「新增部署作業」(會產生新網址,網頁就要跟著改)。改用:

1. 貼上新版 `Code.gs` 並儲存
2. 「部署」→「**管理部署作業**」
3. 選原本那個部署 → 按右上鉛筆「編輯」
4. 「版本」選「**新版本**」→ 按「部署」

網址不變,網頁不用改。

## 圖片存在哪裡?

第一次有人送出圖時,程式會在你的 Google 雲端硬碟自動建立資料夾 `tg_chalkboard`,裡面只有兩個檔:

- `latest_to_husband`:最新一張給老公的圖
- `latest_to_wife`:最新一張給老婆的圖

每次送出都會覆蓋舊的,不留歷史。請不要手動刪改這個資料夾。(就算不小心刪了也不會壞:丟到垃圾桶的話程式照常運作;從垃圾桶永久刪除的話,下次有人送出時會自動重建。)

## 常見問題

| 網頁顯示 | 原因與處理 |
|---|---|
| 通關碼錯誤 | 網頁輸入的跟第 3 步設定的不同 → 在網頁按「重設身分」重新輸入 |
| 後端尚未設定通關碼 | 第 3 步的屬性名稱打錯,要是 `SHARED_SECRET` |
| 網路連線失敗 | 網址貼錯,或第 5 步「誰可以存取」沒選「任何人」 |
